-Desvantagens:
 .Obsoleto se comparado com interno ou externo
 .Sujo,acaba enchendo o codigo limpo de html com estilização
   ``ex: <p background =" yelow";>Olá mundo, de fundo amarelo. </p> ``
 .Lento em composição e alteração
 .Evitar

# Aula10 - css interno
-Desvantagens:
 .Obsoleto se comparado com externo.
 .Sujo,acaba deixando o codigo html maior.
 .Acaba ficando cansativo para muitas paginas.
-Vantagens:
 .Para estilização especifica de algo,ou de tela,de modo que não queira muitos arquivos css
 .Visivelmente facil de atualizar para sites pequenos

# Aula11 - css externo
-Vantagens:
 .Ele pode estilizar varios arquivos html ao mesmo tempo
 .Posui mais funcionalidades como regras: ``@charset "UTF-8";``
 .Ele bem mais organizado,bem mais implicito na pagina html

# Ordem hierárquica
-1°: inline: ele se sobresai ao estilizar um pagina.
-2°: interno: ele se sobresai ao estilizar um pagina mas primeiro vem o inline.
-3°: externo: ele é ultimo a se ler,ele perde na ordem de estilização,contundo é mais versatil e pratico.
