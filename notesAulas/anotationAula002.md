# Comentarios:
-Como comentar no html : `<!--Seu comentario -->`.

# Como deixar em negrito:
-Utilizando o `<strong>Seu texto</strong>`
----
# Simbolos especiais:
-`&reg;`: Marca registrada.
-`&copy;`: Marca de copyright.
-`&trade;`: Marca registrada em inglês.
-*Dica:*Para os simbolos em geral são as inicias do  nome em inglês
-`Exemplo: &yen; ,&dollar; ,&real; &nexist;..`
----
# Emojis
Comumente inseridos via código decimal/hexadecimal ou inserção direta (*não recomendada sem codificação UTF-8 explícita*).
- **Referência:** [W3Schools - HTML Emojis](https://www.w3schools.com/html/html_emojis.asp)
- *Exemplo de código:* `&#128511;` (🗿)
