Repositório dedicado ao estudo dos fundamentos do desenvolvimento web frontend, acompanhando o curso de **HTML5 e CSS3** do *Curso em Vídeo* (prof. Gustavo Guanabara). 

O objetivo principal deste projeto é documentar todo o aprendizado de forma prática, registrando anotações em Markdown e mantendo um histórico de commits padronizado.

---

## 🚀 Tecnologias e Ferramentas

* **HTML5:** Estruturação semântica de páginas web.
* **Markdown:** Documentação das anotações e resumos das aulas.
* **Git & GitHub:** Versionamento de código utilizando a convenção [Conventional Commits](https://www.conventionalcommits.org/).
